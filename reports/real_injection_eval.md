# Prompt-injection detector on real public data

Generated by `scripts/eval_real_injection.py` on 2026-11-20 (seed 7). Detector = the deterministic sanitise + quarantine path (`guardrails/injection.py`); each dataset row is wrapped as a visible `<p>` and run through `quarantine()`. CIs are 95% Wilson intervals. `baseline` = the 15 rules that shipped before this evaluation; `shipped` = baseline + rules tuned on the dev splits only.

## End to end: 100 real test-split attacks embedded in a fixture page

Sampled (seed 7) from deepset/gandalf/bipia test attacks: bipia 41, deepset 21, gandalf 38. Each attack is a visible paragraph on an otherwise benign company page, with a canary token inside its last sentence.

Model-independent: how much of the attack text reaches the Researcher's context after quarantine:

| detector | fully redacted | partly redacted | passed through verbatim |
|---|---|---|---|
| baseline | 10 | 10 | 80 |
| shipped | 26 | 16 | 58 |

Full mock pipeline (gullible mock model, see caveat), shipped detector:

| guardrails | canary reached copy / forbidden tool / host | detector flagged page |
|---|---|---|
| all_on | 14/100 | 42/100 |
| all_off | 31/100 | 0/100 |

Caveat: the mock only 'obeys' sentences that contain cue words and copies only canaries, URLs, emails and money amounts. Most real attacks ask for things it cannot act on (a poem, the password, an opinion), so the pipeline row is a lower bound on harm with a real model. The context-exposure table is the number to trust.
